THIS SCRIPT IS FOR DEBIAN SYSTEMS ONLY!!

This script updates and checks for flatpaks, then system upgrades, then if you have nvidia drivers it checks to verify they are still intact, if not it will ask if you want to rebuild them. The script then notifies you if you must do a system reboot.

To run this script you must:

Download and copy/move this file into your home folder.
Make it executable using "chmod +x systemupgrade.sh".
Run it using "sudo bash systemupgrade.sh".
